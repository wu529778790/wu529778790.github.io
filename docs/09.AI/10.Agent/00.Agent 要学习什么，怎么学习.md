## 先看终点：Agent 全栈岗要准备什么

**面试题方面**，按主题分成几类：

- RAG 篇
- Tool / MCP / Skill 篇
- LangGraph 篇
- Memory 篇
- 评测篇
- 大模型原理篇

![面试准备](https://gcore.jsdelivr.net/gh/wu529778790/img.shenzjd.com@master/blog/20260807114539.png)

## 学习主线：LangChain → LangGraph → DeepAgents

学习主线从 **LangChain** 开始，基于它学习 Agent 基础，掌握这些核心组件：

- ChatModel
- Tool Call
- MCP
- RAG
- Memory
- Structured Output
- Prompt Template

LangChain 的核心能力是把各类组件拼装成链式流程（Chain），通过 LCEL 声明式语法快速串联业务链路。但 Chain 本质偏向线性执行，**原生不支持循环、多分支、复杂跳转**，面对复杂的 Agent 场景能力受限。

所以接下来学习 **LangGraph**——Agent 的图编排引擎。它底层依旧复用 LangChain 的全套组件，在此之上新增了图编排能力：State 状态、节点、边、检查点 Checkpoint 等。

![20260807121334](https://cdn.jsdmirror.com/gh/wu529778790/img.shenzjd.com@master/blog/20260807121334.png)

借助图模型，可以实现循环、条件分支、并行执行、多 Agent、会话中断恢复等复杂能力。

不过 LangGraph 是底层编排框架，很多 Agent 通用能力需要自己从零实现。如果想用基于 LangGraph 进一步封装的方案，可以学一下 **DeepAgents**——它内置了任务规划、多 Agent、Skill 等现成能力，开箱即用。

![20260807121455](https://cdn.jsdmirror.com/gh/wu529778790/img.shenzjd.com@master/blog/20260807121455.png)

## 补齐后端能力

业务的 Agent 都跑在后端环境里，市面上的 Agent 开发基本都是全栈岗，所以要顺带补齐后端能力：

- **Docker Compose** 跑本地环境
- 向量数据库 **Milvus**
- 关系数据库 **MySQL、PostgreSQL**
- 全文检索数据库 **ElasticSearch**
- 缓存中间件 **Redis**
- 对象存储 **Minio、RustFS**
- 图数据库 **Neo4j**
- 消息队列 **RabbitMQ**

另外会讲一下后端框架 **Nest** 的基础。

![30ee7e4d2534da8de1cd27c59522b02d](https://cdn.jsdmirror.com/gh/wu529778790/img.shenzjd.com@master/blog/30ee7e4d2534da8de1cd27c59522b02d.png)

## Agent 全链路监测

之后查缺补漏，讲 Agent 的全链路监测方案 **LangSmith、LangFuse**，记录 Agent 完整运行链路：

- 用户输入
- 大模型调用
- 工具调用
- 报错
- token 消耗与耗时数据

可视化复现 Agent 的思考与工具执行过程，方便排查死循环、参数错误、响应慢等问题，做全链路观测。还能跑一些 RAG 指标的评估实验。

![20260807121557](https://cdn.jsdmirror.com/gh/wu529778790/img.shenzjd.com@master/blog/20260807121557.png)

## 大模型底层原理（了解即可）

还会讲解大模型底层原理，比如 Transformer 架构、单向/双向注意力、训练/推理阶段、自回归生成等。但主要目标是学 Agent 开发，大模型底层原理**了解即可**，不必深入。

![20260807121732](https://cdn.jsdmirror.com/gh/wu529778790/img.shenzjd.com@master/blog/20260807121732.png)

## 项目实战：企业级知识库项目

学完基础之后进入项目实战——**企业级知识库项目**，综合运用前面学到的后端技术和 Agent 框架。

大部分公司的 Agent 项目是围绕 RAG 来的，说明企业需求主要集中在这里。所以实战项目也选择最适配企业需求的场景来做。

![20260807121759](https://cdn.jsdmirror.com/gh/wu529778790/img.shenzjd.com@master/blog/20260807121759.png)

## 语言问题：Agent 开发是语言无关的

课程用 TypeScript 讲，但 LangChain、LangGraph 的 API 在 Python 里是一样的，Agent 的实现方案是语言无关的，所以学 Agent 用啥语言都行。

不过简历上可以写 Python 技能，这样岗位匹配度更高。很多同学学完入职后，都是指挥 AI 用 Python 写 Agent——重点是 Agent 相关的学习，这是语言无关的。

![20260807121838](https://cdn.jsdmirror.com/gh/wu529778790/img.shenzjd.com@master/blog/20260807121838.png)

## 总结

整条学习路线可以概括为：

1. **Agent 基础**：从 LangChain 开始，掌握 ChatModel、Tool Call、MCP、RAG、Memory 等核心组件
2. **Agent 框架**：LangGraph 图编排引擎，以及基于它封装的 DeepAgents
3. **后端基础**：Docker Compose、PostgreSQL、Redis、ElasticSearch、RabbitMQ、Minio、Milvus 等
4. **项目实战**：企业级知识库项目，把前面学的综合运用一遍
5. **简历参考**：大量真实 Agent 简历，借鉴项目背景、技术栈、实现方案来理清思路
6. **面试押题**：真实高频 Agent 面试题，面试时答题思路更清晰

脑子里有了这条路线，后面学起来就更有方向感了。
