## 先看终点：Agent 全栈岗要准备什么

学习之前先想清楚目标。如果目标是 Agent 全栈岗位，面试题基本就集中在这些主题上：

- RAG 篇
- Tool / MCP / Skill 篇
- LangGraph 篇
- Memory 篇
- 评测篇
- 大模型原理篇

![面试准备](https://gcore.jsdelivr.net/gh/wu529778790/img.shenzjd.com@master/blog/20260807114539.png)

先看终点有个好处：知道面试考什么，学起来就不会跑偏，每个阶段都清楚自己在为什么做准备。

## 学习主线：LangChain → LangGraph → DeepAgents

我的主线从 **LangChain** 起步，先把 Agent 的基础组件逐个过一遍：

- ChatModel
- Tool Call
- MCP
- RAG
- Memory
- Structured Output
- Prompt Template

LangChain 的核心价值是把这些组件用链式流程（Chain）串起来，配合 LCEL 声明式语法，业务链路能很快搭出来。但 Chain 本质上是线性执行，**原生不支持循环、多分支和复杂跳转**，碰到真正的 Agent 场景就有点吃力。

所以下一步是 **LangGraph**——面向 Agent 的图编排引擎。底层依旧复用 LangChain 那套组件，只是在此基础上增加了图编排能力：State 状态、节点、边、检查点 Checkpoint 等。

![20260807121334](https://cdn.jsdmirror.com/gh/wu529778790/img.shenzjd.com@master/blog/20260807121334.png)

有了图模型，循环、条件分支、并行执行、多 Agent、会话中断恢复这些复杂能力就都能实现了。

不过 LangGraph 毕竟是底层编排框架，很多 Agent 通用能力得自己从零实现。如果不想重复造轮子，可以看看基于 LangGraph 封装的 **DeepAgents**——任务规划、多 Agent、Skill 这些能力都内置好了，开箱即用。

![20260807121455](https://cdn.jsdmirror.com/gh/wu529778790/img.shenzjd.com@master/blog/20260807121455.png)

## 后端能力也不能落下

Agent 业务最终都跑在后端环境里，市面上的 Agent 开发基本都是全栈岗，所以后端这摊也得补齐：

- **Docker Compose** 跑本地环境
- 向量数据库 **Milvus**
- 关系数据库 **MySQL、PostgreSQL**
- 全文检索数据库 **ElasticSearch**
- 缓存中间件 **Redis**
- 对象存储 **Minio、RustFS**
- 图数据库 **Neo4j**
- 消息队列 **RabbitMQ**

另外再补一下后端框架 **Nest** 的基础。

![30ee7e4d2534da8de1cd27c59522b02d](https://cdn.jsdmirror.com/gh/wu529778790/img.shenzjd.com@master/blog/30ee7e4d2534da8de1cd27c59522b02d.png)

## Agent 全链路监测

再往后是查缺补漏，把 Agent 的可观测性补上。用 **LangSmith、LangFuse** 这类方案记录 Agent 的完整运行链路：

- 用户输入
- 大模型调用
- 工具调用
- 报错
- token 消耗与耗时数据

这样能把 Agent 的思考过程和工具执行过程可视化复现出来，排查死循环、参数错误、响应慢这类问题会方便很多，顺便还能跑一些 RAG 指标的评估实验。

![20260807121557](https://cdn.jsdmirror.com/gh/wu529778790/img.shenzjd.com@master/blog/20260807121557.png)

## 大模型底层原理：了解即可

大模型底层原理也会过一遍，比如 Transformer 架构、单向/双向注意力、训练/推理阶段、自回归生成等。但我的重心是 Agent 开发，这部分**了解即可**，不必深挖。

![20260807121732](https://cdn.jsdmirror.com/gh/wu529778790/img.shenzjd.com@master/blog/20260807121732.png)

## 项目实战：企业级知识库

基础学完就进入实战——**企业级知识库项目**，把前面的后端技术和 Agent 框架综合运用一遍。

选这个方向不是随便挑的：大部分公司的 Agent 项目都围绕 RAG 展开，说明企业需求集中在这里。实战就挑最贴合企业需求的场景来做，性价比最高。

![20260807121759](https://cdn.jsdmirror.com/gh/wu529778790/img.shenzjd.com@master/blog/20260807121759.png)

## 语言无关：TypeScript 还是 Python 都行

Agent 开发是语言无关的。以我自己的笔记为例，示例用 TypeScript 写，但 LangChain、LangGraph 的 API 在 Python 里完全一致，实现方案是通用的，用什么语言学都不影响。

不过简历上写 Python 技能，岗位匹配度会更高一些。实际工作中，很多人也是指挥 AI 用 Python 写 Agent——重点是 Agent 思路本身，语言只是工具。

![20260807121838](https://cdn.jsdmirror.com/gh/wu529778790/img.shenzjd.com@master/blog/20260807121838.png)

## 总结

整条路线收一下：

1. **Agent 基础**：从 LangChain 开始，掌握 ChatModel、Tool Call、MCP、RAG、Memory 等核心组件
2. **Agent 框架**：LangGraph 图编排引擎，以及基于它封装的 DeepAgents
3. **后端基础**：Docker Compose、PostgreSQL、Redis、ElasticSearch、RabbitMQ、Minio、Milvus 等
4. **项目实战**：企业级知识库项目，把前面学的综合运用一遍
5. **简历参考**：多看看真实 Agent 简历，借鉴项目背景、技术栈、实现方案来理清思路
6. **面试押题**：高频 Agent 面试题过一遍，答题思路更清晰

脑子里有了这条路线，后面学起来就有方向感了。
