# Auto-Redbook-Skills：文案、配图与发布的完整流水线

> 整理日期：2026-08-07
> 一套可落地执行的小红书内容流水线，不是一条"帮我写小红书"的提示词。

---

## 流水线四步

1. **写作**：Agent 根据资料生成不超过 20 字的标题、短段落正文和标签；另整理一份适合图片渲染的 Markdown，避免把发布正文原样塞进卡片。
2. **配图**：Playwright 把内容渲染成 1080×1440 的封面与正文图；8 套主题可选视觉气质。
3. **检查**：生成普通 PNG，发布前逐张检查标题换行、图文层级和品牌一致性。
4. **发布（可选）**：脚本从本地环境读取 Cookie，通过 xhs 客户端上传图片和文案，默认仅自己可见，显式开启公开参数才对外发布。

## 四种分页模式

主题与分页是显式参数，按内容篇幅选择：

| 模式 | 适用场景 |
|------|---------|
| 固定缩放 | 内容短 |
| 自动拆页 | 内容长 |
| 手动分隔 | 需要严格控制节奏 |
| 动态高度 | 自定义篇幅 |

关键不是让模型决定所有细节，而是把排版决策交给创作者。

## 值得借鉴的点

真正有价值的不是"一键全自动"，而是把**写作、排版、检查和发布拆成清楚的阶段**，每一步都能替换、预览和回退。

## 限制与风险

- Cookie 不能提交到仓库，过期需要更新
- 短时间高频发布可能触发风控
- 平台已提醒打击 AI 托管运营账号，公开前仍应由人检查事实、语气、版权和频率

**适用定位**：个人创作者适合做稳定初稿和批量排版；品牌团队更适合作为人审前的生产工具，而不是无人值守的账号运营器。
