## 单篇文章结构模板

1. 开头 3 秒抓人：一个具体场景
2. 痛点放大：描述读者正在经历的麻烦
3. 亮出方案：这个工具，一句话说明它能干嘛
4. 实操演示：截图/动图展示怎么用
5. 背后的故事：为什么做、踩了什么坑（塑造独立开发者人设）
6. 引导：关注公众号 → 回复关键词拿链接 / 去 GitHub 点 star
7. 系列预告："下一篇：我做的 XX 工具"

## 更新节奏

- 新号阶段：每周 2 篇（周中干货 + 周末轻松向）
- 每篇写完 → 标题 8 选 1 → 推草稿箱 → 后台核对排版 → 手动发布
