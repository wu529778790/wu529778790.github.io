# WorkBuddy 公众号图文生成与推送草稿箱

> 整理日期：2026-08-07
> 把「写文案 → 挑图 → 排版 → 发布」的 2-3 小时流程，压缩成「准备素材 → 一句话指令 → 校对 → 一键推送草稿箱」。

---

## 五步流程

1. **准备素材**：本地文件夹放照片 + 文字素材（活动说明、项目简报）+ 参考链接（往期推文，告诉 AI "照这个风格写"）。图片必须放在本地文件夹里，推图工具需要本地路径才能上传，直接拖进对话框的图片推送后会丢失。
2. **一句话生成图文**：在工作空间选定素材文件夹，输入指令（模板见下）。
3. **修改校对**：截图圈出问题区域发回对话框，直接说"这里名字写错了帮我修正""小标题颜色改成蓝色"，AI 精准定位修改，不影响其他内容。
4. **配置公众号凭证**（仅首次）：见下方配置步骤。
5. **一键推送草稿箱**：说"把这篇图文发到公众号后台草稿箱"，AI 调用凭证自动存入草稿。⚠️ 推的是草稿箱不是直接发布，建议最后自己登录后台核对排版后再手动发布。

## 生成指令模板

```
请根据"XXX项目"文件夹里的活动素材和照片，帮我生成一篇公众号图文。文章风格参考链接：https://mp.weixin.qq.com/s/xxxxx

要求：
1、标题有温度，正文图文穿插，800字左右。
2、排版格式必须是微信公众平台兼容格式（避免推送后样式丢失）：
（1）所有颜色、字体、间距等样式用 inline style
（2）小标题用 <h2> 标签，颜色可以用机构品牌色（如有）
（3）不要用阴影、圆角、flex 布局等微信不支持的样式
（4）图片 <img> 标签，宽度设为 100%
3、生成后同时给我一个 HTML 文件（用于预览）和可以直接推送到公众号的内容。
```

进阶：熟悉后可以把生成 + 推送合成一条指令，全流程连轴跑。

## 公众号凭证配置

1. **获取 AppID / AppSecret**：微信开发者平台（developers.weixin.qq.com/platform）扫码登录 →「我的业务与服务」→「我的业务」→「公众号」→ 基本配置页。AppID 直接可见；AppSecret 默认隐藏，点「重置」获取（只显示一次，务必复制保存）。
2. **配置 IP 白名单**：同一页面「开发密钥」→「API IP 白名单」填入当前上网的公网 IP。IP 变化会导致推送失败，届时更换新 IP 即可。
3. **安装技能**：WorkBuddy 技能市场搜「公众号自动发布」并安装，按引导填入凭证，记住后无需重复输入。

## 要点

- 文字素材不止活动说明：执行报告、签收记录、受益人反馈截图都可以扔给 AI 提取关键信息。
- 多轮修改是常态：标题不满意 → "再改两版给我选"；段落啰嗦 → "第三段缩短一半"；要加呼吁 → 直接说加一句。
- 推送到的是**草稿箱**，不是直接发布；发布前务必人工核对。

## 进阶：做成自动化 Agent 服务

把这套流程部署成自己的服务：Docker 部署到云服务器，给公众号发消息，AI 自动整理成图文并推进草稿箱。

```
你(微信对话) ──发素材/链接──▶ 微信公众平台 ──消息回调──▶ 你的云服务器(Docker 容器)
                                                         │
                                                         ① 消息入口 · 签名校验
                                                         ② AI Agent · 抓素材 + 生成图文
                                                         ③ 公众号 API · 传图 + 建草稿
                                                         │
                                                         ▼
                                               公众号草稿箱(手动发布)
                                                         │
                     ──客服消息通知"草稿已生成"──────────────┘
                               ▲
                               └──▶ 你(微信对话)
```

**个人订阅号权限**（关键结论：草稿箱可用、发布不可用）：

| 能力 | 个人未认证订阅号 |
|------|:---:|
| access_token | ✅ |
| 素材管理（传图） | ✅ |
| 草稿箱接口 draft/add | ✅ |
| 发布接口 freepublish | ❌ 已回收（2025-07 起） |

→ 个人订阅号恰好和"自动进草稿、人工发布"的流程吻合：**自动生成 + 自动建草稿，发布永远人工**，反而更简单合规。

**几个现实门槛**：

- 微信消息回调要求**已备案域名 + 80/443 端口**（国内服务器需 ICP 备案）
- 被动回复限 **5 秒** → 必须异步：先秒回"收到"，后台生成，完成用客服消息（48h 窗口）通知
- 文章图片是外链，发布前必须转存微信素材库（`media/uploadimg`），否则发布后图片失效
- 订阅号每天发布频次有限；平台打击 AI 托管运营——自动建草稿合规，自动发布有风控风险

**落地顺序**：先到公众号后台「设置与开发 - 接口权限」页确认草稿箱可用 → 本地跑通 LLM 生成微信兼容 HTML → 手动调一次 `draft/add` 建草稿（验证 AppID/Secret/白名单）→ 最后再上 Docker + 域名 + 微信回调。
