# 全网找资源的最强姿势，一个搜索框搞定

找资源这件事，十个人里有九个被坑过。

想看的电影、想听的课、想找的软件安装包、想下的电子书，打开网盘搜索网站，输入关键词，出来的结果一半是广告，一半链接早就失效。点进去，不是让你关注公众号，就是提示文件已删除。挨个网站试一遍，一个晚上就没了。

今天分享一个工具，直接解决这个问题：**PanHub，一个搜索框搜遍全网网盘资源**。

## 它强在哪

**同时搜 80+ 个 Telegram 频道和 20+ 个第三方搜索源**。以前你要开一堆网站挨个试，现在输入一次关键词，结果全部聚合过来，去重、按优先级排好。省的不只是时间，是命。

更实用的是这几点：

**1. 资源比较新**

搜索源是实时更新的频道，热门资源一出来就能搜到，不用等资源站慢慢搬运。

**2. 内置豆瓣影视榜单**

想找片但不知道看什么？内置豆瓣 Top250 和 12 个分类榜单，看到感兴趣的，点一下直接发起网盘搜索。找片流程从"想片名 → 搜索"变成"刷榜单 → 点一下"。

**3. 免费开源零广告**

纯开源项目，代码全公开，没有会员、没有限速、没有充值入口，也没有"回复关键词获取地址"这类套路。

## 用起来什么样

打开就能用，不用注册不用装：

- 搜索：输入关键词，实时返回聚合结果
- 热搜：看看别人都在搜什么，点一下就搜
- 深色模式：自动跟随系统，晚上不刺眼

支持 Vercel、Cloudflare Workers、Docker 一键部署，Docker 一条命令：

```bash
docker run --name panhub -p 4000:4000 -d ghcr.io/wu529778790/panhub.shenzjd.com:latest
```
