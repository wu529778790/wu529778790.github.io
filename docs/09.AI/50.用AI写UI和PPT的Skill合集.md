# 用 AI 写好 UI 与 PPT 的 5 个 Skill（附链接）

> 来源说明：这些 Skill 的聚合站在 **skills.sh**（`www.skills.sh`，注意带 s）。本文所有链接均已逐一打开验证。另有同名停放域名 skill.sh（Park.io 停车页），注意别混淆。

这 5 个 Skill 是目前社区里「用 AI 写好 UI / PPT」的代表，侧重点各不相同：有的管**审美约束**（不让 AI 出廉价设计），有的管**交付物**（高保真原型 / PPT / 动画），有的管**工程化**（原生可编辑 PPTX）。按需取用。

## 逐个介绍

### 1. apple-design — emilkowalski（审美约束类）

- **作者**：Emil Kowalski，Vercel 前设计工程师（曾在 Linear 工作），把苹果 WWDC 设计演讲（尤其是 WWDC 2018《Designing Fluid Interfaces》）提炼成 AI 可读的设计规范。
- **定位**：防止 AI 输出「紫蓝渐变 + 圆角卡片」的廉价 AI 味设计，强制苹果式的克制美学、弹簧动效、物理惯性、排版层级。
- **链接**：[skills.sh 页面](https://www.skills.sh/emilkowalski/skills/apple-design) · [GitHub 仓库](https://github.com/emilkowalski/skills)
- **安装**：`npx skills@latest add emilkowalski/skills`
- **仓库还包含**：animation-vocabulary、improve-animations、review-animations、emil-design-eng 等动效链路 Skill。
- **适用**：审查 / 指导界面交互与动效，给 Claude Code、Cursor、Codex 装上后默认遵循。

### 2. huashu-design — 花叔（交付类）

- **作者**：花叔（alchaincyf），不写代码但用 AI 做出了 AppStore 付费榜 Top1 的「小猫补光灯」。
- **定位**：Claude Code 里用 HTML 做高保真原型、幻灯片、动画和信息图。内置 20 种设计哲学、5 维度专家评审、可导出 MP4 / GIF / 可编辑 PPTX。MIT 协议，个人与商用免费。
- **链接**：[skills.sh 页面](https://www.skills.sh/alchaincyf/huashu-design/huashu-design)（41.5K 安装）· [GitHub 仓库](https://github.com/alchaincyf/huashu-design)
- **安装**：`npx skills add alchaincyf/huashu-design`
- **适用**：给老板演示、给投资人 Demo、团队没有专职设计师时撑起原型工作。典型耗时 3–30 分钟交付成品。

### 3. guizang-ppt-skill — 归藏（演讲 PPT 类）

- **作者**：归藏（op7418），知名 AI 产品博主，把十几年做 PPT 的经验压进了这个 Skill。
- **定位**：生成单文件 HTML 横向翻页 PPT。内置三套视觉系统：Style A 电子杂志 × 电子墨水（Monocle 风）、Style B 瑞士国际主义（网格 + 锚点色 + 极致字号对比）、Style C 华为企业汇报。
- **链接**：[skills.sh 页面](https://www.skills.sh/op7418/guizang-ppt-skill/guizang-ppt-skill)（22.3K 安装）· [GitHub 仓库](https://github.com/op7418/guizang-ppt-skill)
- **安装**：`npx skills add op7418/guizang-ppt-skill`
- **适用**：线下分享、行业演讲、AI 产品发布会、Demo Day 这类强个人风格场合。

### 4. ppt-master — Hugo He（工程化类）

- **作者**：Hugo He，财务投资背景（CPA / CPV），受够了 AI 出图式 PPT 不能编辑。
- **定位**：产出**原生可编辑的 .pptx**（真实 DrawingML 形状、文本框、图表），不是网页截图、不是图片。基于 Python 工具链 + 多角色 AI 工作流（Strategist → Executor → SVG → PPTX），工程化程度最高。
- **链接**：[skills.sh 页面](https://www.skills.sh/hugohe3/ppt-master/ppt-master)（11.1K 安装）· [GitHub 仓库](https://github.com/hugohe3/ppt-master) · [Demo](https://hugohe3.github.io/ppt-master/)
- **安装**：`npx skills add hugohe3/ppt-master`（需 Python 3.10+，`pip install -r requirements.txt`）
- **适用**：投资咨询、企业汇报、客户交付——需要对方能双击编辑的正式 PPT。

### 5. open-design — nexu-io（全能大杂烩类）

- **定位**：本地优先、开源的 Claude Design 替代品。把 Claude Code / Codex / Cursor 等 20+ 编码 Agent CLI 变成设计引擎，内置 276+ Skills、151 套品牌设计系统，覆盖 web-prototype、dashboard、mobile-app、deck、海报等全场景（连归藏 PPT 也打包在里面）。Apache-2.0，数据本地、BYOK、无平台锁定。
- **链接**：[skills.sh 页面](https://www.skills.sh/nexu-io/open-design) · [GitHub 仓库](https://github.com/nexu-io/open-design) · [官网](https://open-design.ai)
- **安装**：`git clone https://github.com/nexu-io/open-design && cd open-design && pnpm install && pnpm tools-dev`
- **适用**：想有一套本地跑、随时能扩展的完整设计工作台；迭代快，生产环境需留意。

## 怎么选

- 要「不让 AI 出廉价设计」→ **apple-design**
- 要高保真原型 / PPT / 动画一键交付（没设计师的团队）→ **huashu-design**
- 要强设计感的演讲 PPT（杂志 / 瑞士风）→ **guizang-ppt-skill**
- 要真正能编辑的 PPTX 交付给客户 → **ppt-master**
- 要本地、开源、全能的设计工作台 → **open-design**
