# 用 AI 写好 UI 与 PPT 的 6 个 Skill（附链接）

先说个挺扎心的事。

你让 AI 给你做个 PPT，它大概率还你一堆紫蓝渐变加圆角卡片。你盯着那玩意儿，说不上来哪儿不对，但就是觉得廉价，一股子模板味。这不是你的问题，也不是 AI 不够聪明，是它脑子里那套默认审美，实在没什么品味。

你可能觉得，直接让 AI 生成不就行了，为啥还要装这些。我以前也这么想，直到被紫蓝渐变教育了。我今天想聊的，就是怎么把这东西掰过来。

现在社区里流行一种东西，叫 skill。你把一套规则写成结构化指令，塞给 Claude Code、Codex、Cursor 这些支持 Agent Skills 标准的 agent，它写东西的时候就会照着执行。设计这块的 skill 特别多，我前后翻了几十个，挑出 6 个有代表性的，今天逐个聊，链接和安装命令都给你放这儿了，按需取用。

先说最出名的一个，apple-design。作者 emilkowalski，Vercel 前设计工程师，在 Linear 干过。他把苹果 WWDC 2018 那场《Designing Fluid Interfaces》演讲，提炼成了一套 AI 能读懂的设计规范。这个 skill 干的事很纯粹，管审美约束，专门防 AI 出廉价设计。你给它装上，它默认就按苹果那套克制美学来，弹簧动效、物理惯性、排版层级，都给你按住了。它仓库里还带着 animation-vocabulary、improve-animations、review-animations、emil-design-eng 一串动效链路的 skill，可以一块儿用。装法是 `npx skills@latest add emilkowalski/skills`，页面在 [skills.sh](https://www.skills.sh/emilkowalski/skills/apple-design)，源码在 [GitHub](https://github.com/emilkowalski/skills)。

第二个跟它正好互补，apple-design-skill，作者 naplesblue，圈里叫青椒。如果说 emilkowalski 那套教 AI「怎么动才像苹果」，这套就教 AI「长什么样才像苹果」，macOS 那个 Liquid Glass 液态玻璃风。作者说自己看腻了 Claude 默认那套草纸黄，干脆自己打磨了一套能落地执行的苹果风设计系统。核心理念我挺喜欢，统一表面优于碎片化卡片，玻璃只用于真正重叠的图层，正文全灰度，颜色只留一个强调蓝。克制即奢华。这套目前 skills.sh 还没收录，直接 [GitHub](https://github.com/naplesblue/apple-design-skill) clone 到 `~/.claude/skills/apple-liquid-glass` 就行，纯 Markdown 加 CSS，没有构建没有依赖，里面 design-system、tokens.css、components、patterns、motion 都分好了，还自带一个 review 模式可以审自己的产出。

说到自审，第三个 skill 也很有意思，huashu-design，作者花叔。这人自己不怎么写代码，但用 AI 做出了 AppStore 付费榜 Top1 的「小猫补光灯」，你敢信。他的思路是用 Claude Code 拿 HTML 直接做高保真原型、幻灯片、动画、信息图，内置 20 种设计哲学，5 个维度专家评审，能导出 MP4、GIF，也能导可编辑 PPTX，MIT 协议，个人商用都免费。安装量 41.5K，是这几个里最高的之一。它的场景很实在，给老板演示、给投资人 Demo，团队没专职设计师的时候，3 到 30 分钟就能撑出一版能看的原型。装法 `npx skills add alchaincyf/huashu-design`，[skills.sh 页面](https://www.skills.sh/alchaincyf/huashu-design/huashu-design)、[GitHub](https://github.com/alchaincyf/huashu-design)。

再往下聊，guizang-ppt-skill，作者归藏，做了十几年 PPT 的老博主，把经验全压进这个 skill 了。产出是单文件 HTML 横向翻页 PPT，内置三套视觉系统，Style A 电子杂志加电子墨水，Monocle 那种调调，Style B 瑞士国际主义，网格加锚点色加极致字号对比，Style C 华为企业汇报。装一个等于带了三套模具，下限锁得死死的，很难出丑。线下分享、行业演讲、AI 产品发布会、Demo Day，这种强个人风格的场合特别合适。`npx skills add op7418/guizang-ppt-skill`，[skills.sh](https://www.skills.sh/op7418/guizang-ppt-skill/guizang-ppt-skill) 和 [GitHub](https://github.com/op7418/guizang-ppt-skill) 都有。

如果你要的是真正能改的 PPT，那得看 ppt-master。作者 Hugo He，CPA 和 CPV 出身，财务投资背景，他说自己受够了 AI 出图式 PPT，改都不能改。这套直接产出原生可编辑的 .pptx，真实 DrawingML 形状、文本框、图表，不是网页截图，不是图片。底层是 Python 工具链，加一个多角色 AI 工作流，Strategist 定策略，Executor 干活，SVG 转 PPTX，工程化程度是这六个里最重的。投资咨询、企业汇报、客户交付，需要对方双击就能编辑的场景，选它。装之前记得 Python 3.10 以上，`pip install -r requirements.txt`。`npx skills add hugohe3/ppt-master`，[页面](https://www.skills.sh/hugohe3/ppt-master/ppt-master)、[GitHub](https://github.com/hugohe3/ppt-master)、[Demo](https://hugohe3.github.io/ppt-master/)。

最后一个是个大杂烩，open-design，nexu-io 社区维护的。它想做的是本地优先的开源 Claude Design 替代品，把 Claude Code、Codex、Cursor 这些 20 多个编码 Agent CLI 全变成设计引擎，内置 276 个 skill，151 套品牌设计系统，web-prototype、dashboard、mobile-app、deck、海报全覆盖，连归藏那套 PPT 都打包进去了。Apache-2.0，数据本地，BYOK，无平台锁定。装它比较重，要 clone 下来 `pnpm install` 再 `pnpm tools-dev`，[skills.sh 页面](https://www.skills.sh/nexu-io/open-design)、[GitHub 仓库](https://github.com/nexu-io/open-design)、[官网](https://open-design.ai) 都在。适合想要一套本地跑、随时能扩展的完整设计工作台的人。不过功能全了，每个也就难做深了，迭代快，生产环境用的时候得留意。

看到这儿你可能发现了，这 6 个其实分两条路线。一条做深，比如 ppt-master、apple-design，单点打透，细节经得起落地验证。一条做广，比如 huashu-design、open-design，什么都能做，覆盖广、容易吸流量，但每种风格都难到极致。两条路不是不能兼顾，只是每加一种设计风格，都要重新做落地测试、调细节，成本是真高。

顺着这个话题，我把自己琢磨设计 skill 的一些心得也掏出来，不一定对，反正我自己是这么干的。我不是设计师，纯粹是踩坑踩出来的经验。

1. 约束保下限，品味放上限。用框架和 token 规则保证「不出丑」，把设计判断留给模型。结构不是限制创意，是给它在正确方向上自由。
2. 把品味翻译成可执行规则。不能只跟 AI 说「像苹果」，要把具体字号、色号、不同场景的变体都写进规则，它才听得懂。
3. 反 slop 就是保品牌识别度。AI 的默认产出是平均值，你必须用明确的禁止项去约束，才能保住品牌感。
4. 让 skill 审自己。构建完用自带的 review 模式审自己的产出，主动校验，省注意力。
5. 缺口驱动地补，别预先膨胀。测出缺口就补一条规则、一个模块，回归验证，而不是一上来就预置几百个图标、几十种风格。

那怎么选呢。要不想让 AI 出廉价设计，装 apple-design，想要苹果那套视觉语言，再加一个 apple-design-skill。团队没设计师又急着交原型，huashu-design 最省事。演讲要强设计感，guizang-ppt-skill 锁下限。要交付客户真能编辑的 PPT，ppt-master。想要本地开源全能工作台，open-design。

其实说到底，这些 skill 解决的是同一个问题，把人的品味翻译成机器能执行的规则。以前这事儿靠设计师的经验，靠师傅带徒弟一代一代传，审美这个东西，向来是最难说清、最难传承的。现在它居然被拆成了一堆可以复制、可以安装、可以分享的文本文件，你说这是不是有点神奇。

所以下次 AI 再给你端一坨紫蓝渐变加圆角卡片的时候，你至少知道问题出在哪儿，也知道怎么治了。

AI 时代最贵的不是算力，是品味。而品味，现在也可以被写进 skill 里，装进任何一台机器。
